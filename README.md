# Manual de usuario de G5-Service

Publicado en GitHub Pages: **https://softwareinfra.github.io/gestion-comercial-documentation/**

Este repositorio contiene solo la copia pública del manual. La fuente vive en el repositorio del
frontend (`doc/manual-usuario/`) y la copia se genera allá con `publicacion/construir.py --salida`;
no edites estas páginas a mano, regenéralas desde la fuente.

Cada push a `main` publica el sitio con `.github/workflows/manual-pages.yml`.
